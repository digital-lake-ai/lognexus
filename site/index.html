LogNexus

Git-Native Agent Memory & Model Context Protocol (MCP) Server

npm: @digital-lake/lognexus (v1.6.1) PyPI: lognexus-mcp (v1.6.1) Glama Server Hub (Grade A) GitHub Repository llms.txt (AI Index)

LogNexus transforms Git and GitHub into a persistent, traceable knowledge graph for AI coding agents. It provides zero-overhead coordination, review gates, subtask contracts, and atomic commits without API proxies or network egress.

Quick Install & Client Configuration

Node.js / npm (Universal CLI & MCP)

Run the stdio MCP server directly without manual installation:

npx -y @digital-lake/lognexus mcp

Scaffold repository rules, contracts, and routing:

npx @digital-lake/lognexus init

Python / uvx (PyPI Distribution)

Zero-install MCP stdio launch via uvx:

uvx lognexus-mcp

Or install globally via pip:

pip install lognexus-mcp

Google Antigravity Setup

Register LogNexus in your user config (~/.gemini/config/mcp_config.json) or project configuration (.agents/mcp_config.json):

{
  "mcpServers": {
    "lognexus": {
      "command": "npx",
      "args": ["-y", "@digital-lake/lognexus", "mcp"],
      "eager": true
    }
  }
}
Tip for Antigravity: Adding "eager": true instructs Antigravity to pre-warm the MCP stdio connection immediately upon session startup, avoiding cold-start latency when agents query tools.

Claude Desktop & Cursor Setup

Add LogNexus to your claude_desktop_config.json or .cursor/mcp.json:

Annotated Model Context Protocol (MCP) Tools

LogNexus exposes 12 annotated MCP tools categorized by operational safety. Every tool specifies standardized RFC ToolAnnotations (readOnlyHint, destructiveHint, idempotentHint, openWorldHint) to ensure secure, deterministic tool execution by AI models.

Tool Name Category ToolAnnotations Description
lognexus_status Read-Only ro=true, destr=false, idemp=true, ow=false Inspects repository git branch, active issue, rules routing mode, ecosystem profile, review gate mode, recommended tier, and working-tree scope drift.
lognexus_state_get Read-Only ro=true, destr=false, idemp=true, ow=false Retrieves persistent agent state (.lognexus/state.json) including active subtask, contract boundaries, allowed files, decision budget, and completed history.
lognexus_note_show Read-Only ro=true, destr=false, idemp=true, ow=false Reads structured LogNexus Git Notes attached to a commit under refs/notes/lognexus (standard git-ai v3 format).
lognexus_timeline Read-Only ro=true, destr=false, idemp=true, ow=false Reconstructs the end-to-end task journey and commit history into structured Markdown or Pull Request body descriptions.
lognexus_audit Read-Only ro=true, destr=false, idemp=true, ow=false Programmatically verifies review gate separation (Authored-by ≠ Reviewed-by), contract integrity, and branch compliance against policy profiles.
lognexus_state_sync Write ro=false, destr=false, idemp=true, ow=false Synchronizes local session state with git HEAD, resolving branch switches and commit alignment.
lognexus_state_set_task Write ro=false, destr=false, idemp=false, ow=false Sets or updates the active subtask contract with title, assigned agent, isolation mode, allowed file allowlist, and verification command.
lognexus_state_finish_task Write ro=false, destr=false, idemp=true, ow=false Marks a subtask finished in session state, recording commit SHA, completion timestamp, and notes.
lognexus_commit Write ro=false, destr=false, idemp=false, ow=false Executes an atomic commit that validates subtask file allowlists, injects authorship trailers, marks subtask completed, and attaches Git Notes in ~0.15s.
lognexus_note_attach Write ro=false, destr=false, idemp=true, ow=false Attaches structured session context and causation metadata to a commit under refs/notes/lognexus without altering the commit SHA.
lognexus_state_clear State-Reset ro=false, destr=true, idemp=true, ow=false Resets the active subtask contract or clears the full task list to recover from erroneous agent state transitions.
lognexus_telemetry State-Reset ro=false, destr=false, idemp=false, ow=false Records local Zero-PII events or queries telemetry state. Strictly local storage in .lognexus/telemetry.json; zero network calls.

MCP Resources & Prompts

MCP Resources (3 Live URIs)

  • lognexus://state — Real-time JSON snapshot of active issue, current subtask contract, and completion history.
  • lognexus://routing — Declarative ecosystem routing configuration (.lognexus/routing.md) defining orchestration and review gates.
  • lognexus://handoff — Automated context handoff document (.lognexus/handoff.md) with live scope-drift report and next actionable prompt.

MCP Prompts (2 Guided Workflows)

  • lognexus-plan — Guides the AI agent through strict task decomposition into contract-bounded subtasks T1..Tn.
  • lognexus-review — Guides independent reviewer models through pre-merge verification, diff auditing, and signature generation.

Architecture & Zero-PII Privacy

LogNexus operates entirely on your local machine using standard Git facilities:

  • Zero Network Egress: LogNexus does not send code, prompts, tokens, or Git data to external servers or telemetry endpoints.
  • Git Notes Preservation: Metadata is committed under refs/notes/lognexus, preserving pristine commit SHAs without polluting commit histories.
  • Deterministic Contract Boundaries: Subtasks enforce explicit allowlists (allowedFiles) and decision budgets, blocking rogue modifications before they reach a commit.
  • Non-Negotiable Review Separation: Independent review gates verify that Authored-by and Reviewed-by models belong to distinct sessions or providers.
